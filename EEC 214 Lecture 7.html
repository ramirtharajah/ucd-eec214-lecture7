Series-Parallel 2:1 (Buck) Converter¶

Phase 1 ($\phi_1$) Series:

  • $S_1, S_3$ on (short)

  • $S_2, S_4$ off (open)

  • $C_{fly}, C_L$ series

Phase 2 ($\phi_2$) Parallel:

  • $S_1, S_3$ off (open)

  • $S_2, S_4$ on (short)

  • $C_{fly}, C_L$ parallel

Discrete-Time Analysis: Transient Response¶

Initial Conditions $\quad V_{OUT}(t=0) = V_{fly}(t=0) = 0 \text{ V}$

$\quad\quad\quad\quad\quad\quad\quad\;\, V_{OUT}[0] = V_{fly}[0] = 0 \text{ V}$

Cycle n / Phase 1

$$Q_L = C_L V_{OUT}[n-1]$$$$Q_{fly} = C_{fly}(V_{IN} - V_{OUT}[n-1])$$

Cycle n / Phase 2

$$Q_L + Q_{fly} = (C_L + C_{fly})V_{OUT}[n]$$

Use charge conservation to establish recursive difference equation:

$$(C_L + C_{fly}) V_{OUT}[n] = C_L V_{OUT}[n-1] + C_{fly} (V_{IN} - V_{OUT}[n-1])$$$$(C_L + C_{fly}) V_{OUT}[n] = (C_L - C_{fly}) V_{OUT}[n-1] + C_{fly} V_{IN}$$$$V_{OUT}[n] = \frac{C_L - C_{fly}}{C_L + C_{fly}} V_{OUT}[n-1] + \frac{C_{fly}}{C_L + C_{fly}} V_{IN}$$

Steady - State $\quad V_{OUT}[n] = V_{OUT}[n-1] = V_{OUT}$

$$(C_L + C_{fly}) V_{OUT} = (C_L - C_{fly}) V_{OUT} + C_{fly} V_{IN}$$$$(C_L + C_{fly} - C_L + C_{fly}) V_{OUT} = C_{fly} V_{IN}$$$$2 C_{fly} V_{OUT} = C_{fly} V_{IN} \Rightarrow V_{OUT} = \frac{V_{IN}}{2} \quad \checkmark$$

Efficiency $\quad$ Related to $C_L$ voltage ripple $\quad \Delta V = \frac{I_L T}{C_L} \quad \text{(assuming } C_L \gg C_{fly}\text{)}$

Discrete-Time Filter (Frequency Response)

$$(C_L + C_{fly}) V_{OUT}[n] + (C_{fly} - C_L) V_{OUT}[n-1] = C_{fly} V_{IN}$$$$H(z) = \frac{\tilde{V}_{OUT}(z)}{\tilde{V}_{IN}(z)} = \frac{C_{fly}}{(C_L + C_{fly}) + (C_{fly} - C_L)z^{-1}}$$

Steady - state $\quad \lim_{z \to 1} H(z) = \frac{C_{fly}}{2 C_{fly}} = \frac{1}{2} \quad \checkmark$

Alternate Discrete-Time Filter Formulation

Include load (ref. Harjani + his students)

Observation: charge stored on flying cap during $\phi_1$ must be equal to the charge transferred to $C_L$ and load $R_L$ across the entire cycle:

$$(C_L + C_{fly}) V_{OUT}[n] + \underbrace{\overbrace{\frac{V_{OUT}[n] + V_{OUT}[n-1]}{2}}^{\text{average output voltage}} \cdot \frac{1}{R_L} (\underbrace{T}_{\text{period}})}_{\text{average load current}} = C_L V_{OUT}[n-1] + C_{fly}(V_{IN} - V_{OUT}[n-1])$$$$\left(C_L + C_{fly} + \frac{T}{2R_L}\right) V_{OUT}[n] + \left(C_{fly} - C_L + \frac{T}{2R_L}\right) V_{OUT}[n-1] = C_{fly} V_{IN}$$$$H(z) = \frac{\tilde{V}_{OUT}(z)}{\tilde{V}_{IN}(z)} = \frac{C_{fly}}{\left(C_L + C_{fly} + \frac{T}{2R_L}\right) + \left(C_{fly} - C_L + \frac{T}{2R_L}\right) z^{-1}}$$

At steady-state,

$$\lim_{z \to 1} H(z) = \frac{C_{fly}}{\left(C_L + C_{fly} + \frac{T}{2R_L}\right) + \left(C_{fly} - C_L + \frac{T}{2R_L}\right)} = \frac{C_{fly}}{2 C_{fly} + \frac{T}{R_L}}$$$$\lim_{z \to 1} H(z) = \frac{1}{2 + \frac{T}{C_{fly} R_L}} = \frac{1}{2} \cdot \frac{1}{1 + \frac{T}{2 C_{fly} R_L}} \quad \left(f = \frac{1}{T}\right)$$$$= \frac{1}{2} \cdot \frac{1}{1 + \frac{1}{2 C_{fly} f R_L}} = \underbrace{\frac{1}{2}}_{\text{transformer ratio}} \cdot \underbrace{\frac{R_L}{R_L + \frac{1}{2 C_{fly} f}}}_{\text{impedance divider}}$$

Switched-Capacitor Converter Examples¶

1:1 Converter

Phase 1: $S_0$ on (short), $S_1$ off (open) $\quad v_{fly} = V_{IN} \quad V_{OUT} = V_{OUT}[n-1]$

Phase 2: $S_0$ off (open), $S_1$ on (short) $\quad v_{fly} = V_{OUT} = V_{OUT}[n]$

Charge balance:

$$C_{fly} V_{IN} + C_L V_{OUT}[n-1] = (C_{fly} + C_L) V_{OUT}[n] + \underbrace{\left(\frac{V_{OUT}[n] + V_{OUT}[n-1]}{2R_L}\right)T}_{\text{average load current}}$$
$$H(z) = \frac{\tilde{V}_{OUT}(z)}{\tilde{V}_{IN}(z)} = \frac{C_{fly}}{\left(C_{fly} + C_L + \frac{T}{2R_L}\right) + \left(-C_L + \frac{T}{2R_L}\right)z^{-1}}$$

Steady-state $\quad \lim_{z \to 1} H(z) = \frac{C_{fly}}{C_{fly} + \frac{T}{R_L}} = 1 \quad \text{limit as } R_L \to \infty \quad \checkmark$

$$H(z)\bigg\vert{}_{z=1} = \frac{1}{1 + \frac{1}{R_L C_{fly} f}} = \frac{1}{1} \cdot \frac{R_L}{R_L + \frac{1}{C_{fly} f}} \quad\quad\quad R_o = \frac{1}{C_{fly} f}$$

1:2 Converter

Phase 1:

  • $S_0, S_3$ on (short)
  • $S_1, S_2$ off (open)

$\quad\quad\quad\;\; v_{fly} = V_{IN}$

$\quad\quad\quad\;\; V_{OUT} = V_{OUT}[n-1]$

Phase 2:

  • $S_0, S_3$ off (open)
  • $S_1, S_2$ on (short)

$\quad\quad\quad\;\; v_{fly} = V_{OUT}[n] - V_{IN}$

$\quad\quad\quad\;\; V_{OUT} = V_{OUT}[n]$

Charge balance:

$$C_{fly} V_{IN} + C_L V_{OUT}[n-1] = C_{fly} (V_{OUT}[n] - V_{IN}) + C_L V_{OUT}[n] + \left(\frac{V_{OUT}[n] + V_{OUT}[n-1]}{2R_L}\right)T$$$$H(z) = \frac{\tilde{V}_{OUT}(z)}{\tilde{V}_{IN}(z)} = \frac{2C_{fly}}{\left(C_{fly} + C_L + \frac{T}{2R_L}\right) + \left(-C_L + \frac{T}{2R_L}\right)z^{-1}}$$

Steady-state $\quad \lim_{z \to 1} H(z) = \frac{2C_{fly}}{C_{fly} + \frac{T}{R_L}} = 2 \quad \text{limit as } R_L \to \infty$

$$H(z)\bigg\vert{}_{z=1} = \frac{2}{1} \cdot \frac{R_L}{R_L + \frac{1}{C_{fly}f}} \quad\quad\quad R_o = \frac{1}{C_{fly}f}$$

Approach generalizes to an N:1 or 1:N series-parallel switched-capacitor converter quite readily.

Switched-Capacitor Converter Parasitics¶

IC Metal-Insulator-Metal (MIM) Capacitor Parasitics

2:1 Series-Parallel Converter Example

Phase 1: Series

$$v_{t,fly} = V_{IN} \quad\quad E_{t,fly} = \frac{1}{2} C_{t,fly} V_{IN}^2 \quad\quad v_{b,fly} = V_{OUT} \quad\quad E_{b,fly} = \frac{1}{2} C_{b,fly} V_{OUT}^2$$

Phase 2: Parallel

$$\left. \begin{aligned} & v_{t,fly} = V_{OUT} \quad\quad E_{t,fly} = \frac{1}{2} C_{t,fly} V_{OUT}^2 \\[1em] & v_{b,fly} = 0 \text{ V} \quad\quad E_{b,fly} = 0 \text{ J} \end{aligned} \right\} \text{Losses in charge transfer to and from parasitics } C_t \text{ and } C_b$$

Total losses: proportional to $\quad C_{t,fly} (V_{IN} - V_{OUT})^2 + C_{b,fly} V_{OUT}^2$

Charge balance: (unloaded case where $R_L \to \infty$)

$$C_{t,fly} V_{IN} + C_{fly} (V_{IN} - V_{OUT}[n-1]) + C_L V_{OUT}[n-1] + C_{b,fly} V_{OUT}[n-1] =$$$$(C_{t,fly} + C_{fly} + C_L) V_{OUT}[n] + C_{b,fly} \cdot \emptyset \text{ V}$$$$H(z) = \frac{\tilde{V}_{OUT}(z)}{\tilde{V}_{IN}(z)} = \frac{C_{t,fly} + C_{fly}}{(C_{t,fly} + C_{fly} + C_L) + (C_{fly} - C_L - C_{b,fly})z^{-1}}$$

Steady State $\quad \lim_{z \to 1} H(z) = \frac{C_{t,fly} + C_{fly}}{2C_{fly} + C_{t,fly} - C_{b,fly}}$

Assume:

  • $C_{t,fly} = \epsilon_t C_{fly}$
  • $C_{b,fly} = \epsilon_b C_{fly}$
$$H(z) = \frac{1 + \epsilon_t}{2 + (\epsilon_t - \epsilon_b)} \quad\quad\quad\quad\quad \lim_{\epsilon_t, \epsilon_b \to 0} H(z) = \frac{1}{2}$$

Example: $\epsilon_t = 0.01, \quad \epsilon_b = 0.1, \text{ then } H(z)\bigg\vert{}_{z=1} = \frac{1 + 0.01}{2 + 0.01 - 0.1} = \frac{1.01}{1.91} = 0.529$

Alternative Discrete-Time Analysis¶

For some converters, the following modification to the previous analysis matches simulations and measurements more accurately. In particular, the output voltage is assumed to be the same during both phases of the $n\textrm{th}$ cycle. When accounting for the load resistance $R_{L}$, this leads to the following modified difference equation for the 2:1 down converter:

$$ (C_{L} + C_{fly})V_{out}[n] + \frac{V_{out}[n]}{R_{L}}T = C_{L}V_{out}[n-1] + C_{fly}(V_{IN} - V_{out}[n-1]) $$$$ \left(C_{L} + C_{fly} + \frac{T}{R_{L}}\right)V_{out}[n] + (C_{fly} - C_{L})V_{out}[n-1] = C_{fly}V_{IN} $$

In the $z$-transform domain, the transfer function then becomes

$$ H(z) = \frac{\tilde{V}_{out}(z)}{\tilde{V}_{IN}(z)} = \frac{C_{fly}}{\left(C_{L} + C_{fly} + \frac{T}{R_{L}}\right) + (C_{fly} - C_{L})z^{-1}}$$

At steady-state,

$$ \lim_{z\to 1} H(z) = \frac{C_{fly}}{2C_{fly} + \frac{T}{R_{L}}} = \frac{1}{2}\frac{R_{L}}{R_{L} + \frac{1}{2C_{fly}f}} $$

This is the same steady-state result derived before, but the difference equation and the corresponding discrete-time transfer function are different.

# =============================================
# Switched Capacitor 2:1 Voltage Down Converter
# =============================================
VIN   =  1.8     # Input voltage (V)
RLlg  =  1.0e10  # Load resistance - large (ohms)
RLsm  =  1.0e5   # Load resistance - small (ohms)
Cfly  =  10*5.0e-12 # Fly capacitance (F)
# CL    = 50.0e-12 # Load capacitance (F)
CL    = 20*Cfly  # Load capacitance (F)
Tsw   = 1e-7     # Switching period (s)

Nc   = 1000 # Number of cycles to calculate

# Initialize capacitor state
VoutLg = zeros(Nc) # Light load conditions
VoutSm = zeros(Nc) # Heavy load conditions
Vfly   = zeros(Nc)

nVec = np.arange(0,len(VoutLg)) # Vector of discrete-time indices

for i in range(1,len(VoutLg)):
    VoutLg[i] = ((CL - Cfly)/(CL + Cfly + (Tsw/RLlg)))*VoutLg[i-1] + (Cfly/(CL + Cfly + (Tsw/RLlg)))*VIN
    VoutSm[i] = ((CL - Cfly)/(CL + Cfly + (Tsw/RLsm)))*VoutSm[i-1] + (Cfly/(CL + Cfly + (Tsw/RLsm)))*VIN  

figNum = 1    
plt.figure(figNum,figsize=(24,12)) # Figure size in in. x in.
VOUTplot  = plt.plot(nVec, VoutLg, \
                    '-bo',label='$V_{out}$ (Light Load)')
VOUTplot  = plt.plot(nVec, VoutSm, \
                    '-ro',label='$V_{out}$ (Heavy Load)')
plt.grid([VOUTplot])

# x-axis range
nLimit = Nc/10

plt.axis([ -10, nLimit, -0.1, 1.01])

plt.xticks(np.arange(0,nLimit+1,10)) # Add one to get the last tic line.

plt.yticks(np.arange(0,1.1,0.1))
plt.xlabel('Cycle (n)')
plt.ylabel('Output Voltage $V_{OUT}$ (V)')
plt.title('Discrete-Time Calculation Switched Capacitor 2:1 Converter')
plt.legend()
plt.show()

Ro = Tsw/(2*Cfly) # Output impedance (ohms)
print("Output Impedance Ro = {0:7.3f} (ohms)".format(Ro))

print("\nImpedance Divider (Light Load) = {0:12.9f} (ohms)".format(RLlg/(RLlg + Ro)))
print(  "Impedance Divider (Heavy Load) = {0:12.9f} (ohms)".format(RLsm/(RLsm + Ro)))

print("\nCalculated Steady-State Vout (Light Load) = {0:12.9f} (V)".format((0.5*VIN)*RLlg/(RLlg + Ro)))
